# The Kitchen Mod Reborn 0.5.1

## What's new
- **Plates now show what's on them as an item**: a plate carrying a sandwich or other items is drawn with its contents in your hand (first and third person, both hands), dropped on the ground, in item frames, and in the inventory (shrunk to fit the slot). Empty plates look as before.
- Held and dropped plates are the same size as a placed plate; in first person the plate is pushed forward so it is fully visible.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
