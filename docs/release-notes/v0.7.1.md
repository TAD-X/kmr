# The Kitchen Mod Reborn 0.7.1

## Fixes
- The frying pan in your hand is now the same size as the pan on the stove, in first and third person, and is held by its handle.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
