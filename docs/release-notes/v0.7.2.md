# The Kitchen Mod Reborn 0.7.2

## Fixes
- Frying pan in third person is now held at the player's hand by its handle, instead of hanging far from the arm down to the ground.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
