# The Kitchen Mod Reborn 0.4.0

## What's new
- Farming: the original crops (lettuce, tomato, strawberry, peanut) and wild plants, jam jars, and foods.
- Cutting board: build sandwiches (up to 32 layers) in 3D with bread, butter and jam spreads, bacon and all the fillings; cut meat and veg with a knife.
- Sandwiches now show every layer in 3D: on the board, in your hand (first and third person), dropped on the ground, in item frames, and shrink to fit in the inventory.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
