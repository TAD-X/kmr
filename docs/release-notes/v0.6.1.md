# The Kitchen Mod Reborn 0.6.1

## What's new
- **The oven door now swings.** The hatch opens and closes smoothly (a short swing of about a third of a second) instead of snapping, like the original. It animates however the oven changes: you, another player, or a redstone-free command. An oven that was already open when you load the world or walk up to it simply shows open, with no swing. The lit "active" look stays on the hatch.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
