# The Kitchen Mod Reborn 0.5.2

## Plate rules
- A plate with food on it can't be put onto a plate (an empty plate can).
- Items that can't stack (swords, tools...) go on a plate at most once per kind.
- Filled shulker boxes, filled bundles and loaded plates can't be put on a plate; empty ones can.
- Plates can no longer be put inside shulker boxes or bundles.
- When the plate refuses something, a message on the action bar says why. A full plate (32) also tells you.

## Fixes
- An empty plate in your hand is now the same size as a loaded one, in first and third person.
- A plate with a sandwich in first person is held upright, like the sandwich.
- Cutting board item: the inventory shows the standard 3/4 block view, it is visible when held in first person, and sits in the hand like a block in third person.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
