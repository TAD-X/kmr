# The Kitchen Mod Reborn 0.5.0

## What's new
- **Plate**: craft with clay and bone meal (`C B C / _ C _`). It faces the way you were looking when you placed it.
  - Right-click with an item to put one on the plate (up to 32). Right-click with an empty hand to take the top item back.
  - Sneak + right-click picks the plate up with everything on it kept in the item; hover the plate item to see what's on it. Breaking the plate by hand does the same, like a shulker box. Explosions drop the plate and its contents separately.
  - Plain items lie flat and stack up; a finished sandwich sits on the plate at its full cutting board size (one sandwich per plate, anything can go on top).
- Sandwich held in first person: closer to the usual hand position, and eating no longer flings it off to the side.
- Eating a sandwich now shows bread particles instead of missing-texture squares.
- Sandwiches stand on their bottom bun when held in third person, dropped, or in item frames.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
