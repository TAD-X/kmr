# The Kitchen Mod Reborn 0.5.3

## Plate rules (replaces the 0.5.2 rules)
- Unstackable items (swords, tools, a sandwich, bundles...) work like the sandwich: they only go on an **empty** plate, one at a time. So a plate can't be used to squeeze many unstackable items into one inventory slot.
- If the plate won't take what you're holding, it acts as if it were full: right-clicking takes the top item off. There are no more action-bar messages.
- Shulker boxes can't go on a plate at all. Filled bundles and plates with things on them can't either.
- A plate with things on it is now unstackable. Empty plates stay stackable.
- Empty plates (and loaded ones) can go inside shulker boxes and bundles.

## Visuals
- An empty plate on a plate shows as the plate model, nested on the plate below.

## Requires
- Minecraft 26.3
- Fabric Loader 0.20.1 or newer
- Fabric API 0.166.0+26.3

**Both the server and all clients must use the same jar.**
